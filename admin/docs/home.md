# monolith-nomad

An offline knowledge server: Wikipedia, courses, books, maps and local AI on hardware you own. Once downloaded, nothing needs the internet.

![Dashboard](/docs/dashboard.webp)

## Where to start

1. **[Easy Setup →](/easy-setup)**: features, Brazilian maps and Portuguese content in four steps.
2. **[Getting started →](/docs/getting-started)**: requirements, installation and a summary of each tool.

Press **Ctrl K** (or **/**) on any screen to find a page, an app or a Library work.

Update the software and content while you are online, by hand or with [automatic updates](/docs/updates). **[Check for updates →](/settings/update)**
