# Drug Reference

Official **FDA** (US) drug labels, searchable offline: by drug, by condition and side by side.

> **Health information, not medical advice.** It does not replace a doctor, pharmacist or nurse. The labels are US labels in English; names and indications may differ from products sold elsewhere.

The notice above appears on the first visit from each browser.

## Install

- **Content Explorer:** **Medicine** category, **Standard** profile (includes *FDA Drug Reference*), or
- **Drug Reference page:** the download button.

| Stage | Size | Note |
|---|---|---|
| openFDA download | ~1.7 GB | Resumes if the connection drops |
| Indexing | 8 to 10 GB on disk | The longest stage; runs in the background |

Search turns on by itself when indexing finishes.

## Use

| Tab | What it does |
|---|---|
| **Drug** | Search by brand or generic name; results grouped by active ingredient |
| **By condition** | Pick symptoms (fever, burn...); drugs covering all of them come first |
| **FDA data** | Source, state and label count; redo the download or the indexing |

**Compare:** on a drug's page, compare the warnings of two labels. The comparison does **not** compute interactions.

**Updates:** with automatic content updates on, the Drug Reference follows openFDA. Without them, the data stays as installed.
